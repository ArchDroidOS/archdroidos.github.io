# How to install ArchDroidOS

[Download ArchDroidOS ZIPs](https://github.com/ArchDroidOS/ArchDroidOS/releases)
[Download Virtual Master](https://play.google.com/store/apps/details?id=com.clone.android.dual.space)

First: Install Virtual Master on your phone

Go to the "+" icon and then Backup & Restore
Go to the folder icon
Import your ZIP
Restore
Go back and start the VM.
